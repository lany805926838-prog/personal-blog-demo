WorkTrace 是我做的一个本地电脑日志工具。它的作用是记录一天里电脑上主要做了什么，比如使用了哪些应用、浏览了哪些网页、什么时候空闲、哪些文件发生了变化，以及电脑有没有开关机、睡眠、唤醒等系统事件。

我做这个项目，是想让自己每天复盘时不用完全靠记忆，可以从电脑活动记录里看到更接近真实的时间线。

## 我做了什么

我用 Python 写了一个本地 Agent，定时采集当前前台应用、进程名和窗口标题。它还会检测键鼠空闲时间，超过设定时间后把这段记为空闲。

为了更准确记录网页活动，我另外写了一个 Chrome 扩展。扩展会把当前激活标签页的标题、域名和完整 URL 上报给本地 Agent。这样 Dashboard 里就能看到网页访问时间线。

项目还会监听指定目录里的文件变化，比如新建、修改、删除、疑似重命名或移动。Windows 事件日志也会被周期性读取，用来补充开关机、睡眠、唤醒、应用崩溃、登录和锁屏等记录。

所有数据都保存在本地 SQLite 数据库里，并提供一个本地 Dashboard：`http://127.0.0.1:8765/`。页面里可以查看当天统计、应用使用排行、网页访问时间线、文件活动、系统事件和手动备注。

## 用到的工具

- Python：实现本地 Agent、数据采集和 Dashboard 服务。
- SQLite：保存应用活动、网页记录、文件事件和系统事件。
- Chrome Extension：上报当前激活标签页 URL 和标题。
- Windows 事件日志：补充开关机、睡眠、唤醒等系统事件。
- PowerShell：做启动脚本、开机自启动和桌面快捷方式。
- Codex：辅助设计采集逻辑、Dashboard 页面和脚本。

## 项目结果

最后做出了一个可以在本机运行的 WorkTrace Demo。它不会截图、不会录屏、不会记录键盘输入，也不会上传到外部服务器，只是在本地记录应用、网页、文件和系统事件。

这个项目让我练习了本地数据采集、SQLite 存储、Chrome 扩展通信、Windows 日志读取和本地 Dashboard 展示。后续如果继续做，可以把聚合后的时间线交给 AI 生成日报，但原始日志仍然保留在本地。
